# Expense Tracker

## Description

This project is a simple Python Expense Tracker that stores daily expenses in a CSV file. It records the expense date, category, description, and amount while generating a category-wise and total spending report.

## Features

Stores expense records in a CSV file, validates expense amounts, calculates total spending, and displays spending by category.

## Technologies

Python

CSV Module

## Files

expense_tracker.py

expenses.csv

## How to Run

Run the program using Python.

Enter expense details.

View the spending summary.

Expense data is saved automatically in the CSV file.

## Output

Expense records are stored permanently.

Category-wise spending summary.

Total spending report.
